# work-navi 需求文档

> 个人项目资源导航台 · 前后端一体 · 当前阶段自用
> 文档版本:v1.0 ｜ 更新日期:2026-09-01

---

## 1. 产品概述

### 1.1 背景与目标
日常参与多个项目时,各类资源地址(需求文档、环境地址、原型、Git 仓库、数据库连接等)散落在不同工具中,查找和登录凭证记忆成本高。work-navi 提供一个**集中式导航台**:按项目组织所有资源地址与凭证,一键跳转/复制;并以**周为单位**记录任务,支持历史回顾。

### 1.2 目标用户
个人开发者(当前阶段仅本人本机使用,不涉及多用户/权限)。

### 1.3 核心价值
- 一处集中管理多项目的所有资源入口与凭证
- 点击即跳转、一键复制账号密码
- 以周为单位记录任务,历史可追溯

---

## 2. 信息架构

```
work-navi
├── 侧边栏(全局导航,始终可见)
│   ├── 品牌区(Logo + 名称)
│   ├── 全局搜索(项目 / 资源)
│   ├── 任务周记入口(全局,带当前周号徽标)
│   ├── 项目列表(颜色圆点 + 名称 + 资源数)
│   └── 新建项目按钮
└── 主内容区(两个互斥视图)
    ├── 项目视图:项目详情 + 资源卡片 + 本周任务速记
    └── 任务周记视图:当前周编辑器 + 历史周列表
```

主内容区同一时刻只显示一个视图,通过侧边栏切换,导航位置全程固定。

## 3. 功能需求

### 3.1 项目管理

| 编号 | 功能 | 描述 |
|------|------|------|
| P-1 | 项目列表 | 侧边栏展示所有项目,每项含标识颜色圆点、名称、资源数量;当前项目左侧高亮条 |
| P-2 | 新建项目 | 弹窗表单:名称(必填,≤40 字)、描述(选填,≤200 字)、标识颜色(6 色单选)|
| P-3 | 编辑项目 | 项目详情页顶栏「编辑项目」入口,复用同一弹窗并预填当前值 |
| P-4 | 切换项目 | 点击列表项进入对应项目详情视图 |
| P-5 | 项目详情 | 展示名称、颜色、描述、资源总数、更新时间 |

**新建/编辑项目弹窗字段**
- 名称:必填,单行,≤40 字,空值红框提示
- 描述:选填,多行,≤200 字
- 标识颜色:6 色圆点单选(靛蓝/绿/天蓝/橙/粉/紫),选中显示对勾

### 3.2 资源管理

每个项目下按**分类**分组管理资源卡片。

| 编号 | 功能 | 描述 |
|------|------|------|
| R-1 | 资源卡片展示 | 图标、标题、URL、备注、账号/密码行、类型标签 |
| R-2 | 标题点击跳转 | 有 URL 时标题为超链接,新标签页打开(`target=_blank rel=noopener`);hover 显示外链图标 |
| R-3 | 复制账号/密码 | 每行独立复制按钮,点击后按钮短暂变绿反馈 |
| R-4 | 密码掩码 | 密码默认掩码 `••••••`,眼睛图标切换显示/隐藏 |
| R-5 | 无 URL 资源 | 如数据库,标题不跳转,底部提供「复制连接串」按钮 |
| R-6 | 按分类分组 | 资源按分类分区展示,每区有标题、计数、「添加」按钮 |
| R-7 | 分类筛选 | 顶部 chips 筛选(全部/各分类),显示各分类计数 |
| R-8 | 添加资源 | 分类区「添加」按钮打开资源弹窗并预选该分类 |
| R-9 | 编辑/删除资源 | 卡片右上角 kebab 菜单(编辑、删除等操作)|

**资源字段(添加/编辑弹窗)**
- 分类:必填,下拉选择(来自当前分类列表)
- 标题:必填,≤60 字
- 地址 URL:选填(http(s) 或 IP:端口);填写后卡片标题可跳转
- 备注:选填,多行,≤200 字
- 用户名:选填
- 密码:选填,输入框带显隐切换;标注「明文保存 · 仅本机使用」

### 3.3 分类管理

| 编号 | 功能 | 描述 |
|------|------|------|
| C-1 | 分类列表 | 弹窗展示所有分类:颜色圆点、名称、资源数 |
| C-2 | 新增分类 | 输入名称 → 添加(支持回车)|
| C-3 | 删除分类 | 仅**资源数为 0** 的分类可删除;有资源的分类删除按钮禁用并提示原因 |
| C-4 | 分类排序 | 预留拖拽手柄(后续实现拖拽排序)|
| C-5 | 默认分类 | 需求、环境、任务、原型、Git(可增删改)|

入口:筛选栏右侧「管理分类」按钮。

### 3.4 任务周记(全局)

以**自然周(周一起,ISO 周号)**为单位记录任务,全局一份(不区分项目)。

| 编号 | 功能 | 描述 |
|------|------|------|
| T-1 | 当前周编辑器 | 大号 Markdown 文本区,显示周号 + 日期范围(如 `W36 · 8月31日–9月6日`),失焦自动保存 |
| T-2 | 自动切周 | 按自然周切换,每周一自动进入新一周;历史周自动归档 |
| T-3 | 历史列表 | 按年分组,每周一行:`YYYY · 第N周(X月X日–X月X日)` + 摘要 + 条数;当前周标「本周」 |
| T-4 | 历史周详情 | 点击某周打开弹窗,查看并**编辑**该周内容,保存生效 |
| T-5 | 项目页速记 | 项目详情右栏「本周任务」可直接编辑(与当前周编辑器同源),提供「历史 →」跳转任务周记 |

入口:侧边栏「任务周记」(带当前周号徽标)。

### 3.5 全局搜索
- 侧边栏搜索框,快捷键 `/` 聚焦
- 搜索范围:项目名称、资源标题/URL/备注
- (原型为占位,具体检索逻辑在实现阶段细化)

## 4. 交互与状态

| 场景 | 行为 |
|------|------|
| 弹窗关闭 | 支持 X 按钮、取消按钮、点遮罩、Esc 键;关闭后焦点归还触发元素 |
| 弹窗打开 | 自动聚焦首个输入框;遮罩 62% 黑 + 模糊 |
| 表单校验 | 必填项为空时聚焦并红框提示 |
| 复制反馈 | 复制按钮点击后短暂变绿(约 1.2s)|
| 自动保存 | 任务文本区失焦保存,显示「已保存」状态 |
| 视图切换 | 项目视图 ↔ 任务视图互斥,导航高亮同步,滚动位置重置 |
| 空状态 | 分类无资源时显示引导(实现阶段补充)|

## 5. 设计规范

> 由 ui-ux-pro-max 生成的开发者工具设计系统。

- **风格**:深色开发者工具风,微交互
- **配色**:slate 深蓝底(`#0F172A`)+ 绿色主 CTA(`#22C55E`)+ 靛蓝品牌色(`#6366F1`);分类各有专属色相
- **字体**:标题/数据 `Fira Code`(等宽,利于展示 URL/账号),正文 `Fira Sans`
- **圆角**:卡片 14px / 控件 9px
- **动效**:150–300ms,ease-out;遵循 `prefers-reduced-motion`
- **无障碍**:图标按钮均带 `aria-label`;弹窗 `role=dialog` + `aria-modal`;焦点环可见;深色下文本对比度 ≥ 4.5:1;触控目标 ≥ 44px;skip-link

## 6. 数据模型(实现参考)

```
Project { id, name, desc, color, order, createdAt, updatedAt }
Category { id, name, color, order }           // 资源分类,可增删改
Resource { id, projectId, categoryId, title, url, note, username, password, order, createdAt, updatedAt }
WeekNote { id, isoYear, isoWeek, startDate, endDate, content, updatedAt }  // 全局周记,唯一键(isoYear, isoWeek)
```

说明:
- `Resource.password` 明文存储(自用本机);若日后公网部署须先加认证 + 加密。
- `WeekNote` 按 ISO 年+周号唯一;当前周由系统日期计算,不存在则首次编辑时创建。
- `Category` 删除受约束:存在引用它的 `Resource` 时禁止删除。

## 8. 非目标(当前阶段不做)

- 多用户 / 登录 / 权限
- 密码加密存储(自用明文,后续公网化再加)
- 团队协作 / 分享
- 移动端专门适配(桌面 Web 优先,但布局响应式)
- 任务提醒 / 通知

---

## 9. 安全说明

- 密码**明文存储**,服务默认仅监听 `localhost`,仅供本机使用。
- **若日后部署到公网,必须先加入身份认证并对密码字段加密**,否则存在严重泄露风险。
